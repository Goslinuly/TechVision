# Структура затрат (Cost Structure) — §5 ТЗ

Цель — показать, что фронтир-модель на каждое сообщение не разоряет проект, за
счёт архитектурных митигаций (§3): один вызов Fable 5 на сообщение, дешёвый
Haiku на подшаги, локальные поиск/эмбеддинги, кэш вердиктов.

## Цены API (за 1M токенов)

| Модель            | Роль                                | Input  | Output |
|-------------------|-------------------------------------|--------|--------|
| Claude Fable 5    | оркестратор (маршрутизация + синтез)| $10.00 | $50.00 |
| Claude Haiku 4.5  | классификация + извлечение claim'ов | $1.00  | $5.00  |

> Проверять актуальность цен в консоли Anthropic перед защитой.

## Оценка на одно сообщение

Типичное пересланное сообщение — короткое (≈150–400 токенов). Оценка «сверху»
на разбор одного сообщения:

| Шаг                                   | Модель  | ~Input | ~Output | ~Стоимость |
|---------------------------------------|---------|--------|---------|------------|
| Классификация + декомпозиция claim'ов | Haiku   | 500    | 300     | ~$0.0020   |
| Оркестратор: 3–5 tool-use итераций    | Fable 5 | 4 000  | 1 200   | ~$0.100    |
| **Итого на сообщение**                |         |        |         | **≈ $0.10**|

Эмбеддинги и семантический поиск — локально, **$0** за API.

## Митигации (уже в коде)

- **Один** вызов Fable 5 на сообщение — только маршрутизация и синтез
  (`orchestrator.run_tool_loop`).
- Извлечение claim'ов и классификация → Haiku (`services/llm.complete_json`).
- Поиск / эмбеддинги → локально, без API.
- **Кэш вердиктов по хешу утверждения** (`services/cache.py`): одни и те же
  фейки ходят по кругу, повторный разбор не оплачивается.
- Prompt caching системного промпта оркестратора (можно включить далее) —
  ~0.1× цены input на повторных вызовах.

## Хостинг

- Railway / Hetzner VPS — self-hosted FastAPI + бот. Порядок $5–20/мес.
- KazLLM-8B — self-hosted (llama.cpp), только вычисления, без API-платы.

## Устойчивость (соцпроект)

- Измеряемый эффект собирается в `/metrics` (кол-во проверок, распределение
  вердиктов, найденные манипуляции) — база для метрики «% сообщений, где
  пользователь изменил решение делиться».
- Монетизация при CC-BY-NC: гранты (Medianet/Soros), B2G-пилот с акиматами по
  медиаграмотности, white-label для школьных медиа; коммерческая версия — на
  модели без NC-лицензии (roadmap-слайд).
