## 0. Принцип «один пользователь — одна боль» (страница 1 TVEP)

**Пользователь:** школьник/студент, которому в семейный чат (WhatsApp/Telegram) прислали
«новость» на казахском или русском.

**Боль:** он *уже почти поверил* или ему возразили, и он не знает, как проверить и что ответить.
Проблема настигает его **после** контакта с контентом, а не до. Готовых инструментов проверки
на казахском и русском с учётом локального контекста нет — рынок англоязычный.

**USP:** не выносим вердикт «97% фейк» (это ложь — открытые детекторы дают ~78% AUC), а
даём **объяснимый разбор**: какие утверждения проверяемы, что нашлось в базах фактчекеров,
какие манипулятивные приёмы использованы, и как на это ответить. На казахском и русском.

### 2.1. Оркестратор на Fable 5 — почему это НЕ «пустая обёртка над API»

Критерий 2 явно штрафует обёртки. Оркестратор реализует **кастомный агентный цикл**:

1. **Классификация** входящего сообщения: факт / мнение / только манипуляция / смешанное.
   Мнения и прогнозы НЕ проверяем (как и Factcheck.kz — только факты).
2. **Декомпозиция** на атомарные проверяемые утверждения (claim extraction).
   Пример: «Врачи скрывают, что вакцина X вызвала 5000 смертей в Алматы» →
   [«вакцина X вызвала 5000 смертей», «это происходило в Алматы», «врачи скрывают»].
3. **Маршрутизация каждого утверждения** через tool-use (модель сама решает, какой инструмент звать):
   - `search_local_corpus(claim)` — семантический поиск по базе Factcheck.kz
   - `google_factcheck(claim, lang)` — Google Fact Check Tools API
   - `analyze_rhetoric(text)` — детектор манипулятивных приёмов
   - `kazllm_specialist(text)` — для казахских идиом, локальных сущностей, диалектов
4. **Синтез карточки**: не голый вердикт, а структура (см. §4).

Это и есть «RAG-цепочка + агентный цикл» из шаблона TVEP, стр. 2. Логику системного промпта,
схему tool-use и цикл — вынести в TVEP дословно.

### 2.2. Роль локальной модели (USP «локальный контекст»)

`KazLLM-8B-GGUF` (ISSAI, Nazarbayev University — площадка хакатона) вызывается оркестратором
как **специалист по казахскому**: разбор идиом, локальных персонажей, диалектных форм, которые
англоязычная модель понимает хуже. Это буквальный ответ на боль зоны «инструментов на
казахском с локальным контекстом нет».

> «исследовательской глубине» и упоминание в TVEP.

## 4. Формат карточки-разбора (ключевая фича, UI/UX критерий финала №1)

Не «правда/ложь», а структура:

```
📋 РАЗБОР

Проверяемые утверждения:
  • «вакцина X вызвала 5000 смертей»  →  ❌ Опровергнуто (Factcheck.kz, 2025)
  • «в Алматы»                        →  ⚠️ Данные не найдены
  • «врачи скрывают»                  →  💭 Не факт, а предположение — не проверяется

🎭 Манипулятивные приёмы (подсветка в тексте):
  • Апелляция к страху («скрывают»)
  • Конкретная цифра без источника (5000)

💬 Как можно ответить:
  «Официальной статистики по этим смертям нет, а формулировка
   „врачи скрывают" — это домысел, а не проверяемый факт.»

🔗 Полный разбор: aqiqat.kz/r/a8f3
```

Веб-страница по ссылке — то, чем пользователь **делится обратно в чат** (органический рост →
ответ на вопрос жюри про масштабирование без маркетинга).

## 5. Модель решения (страница 3 TVEP)

**Алгоритмическая модель:**
- Semantic retrieval: cosine similarity по эмбеддингам, порог τ для «совпадение найдено».
- Confidence = f(similarity, наличие в Google API, свежесть источника). Формулу выписать явно.
- Rhetoric detection: набор правил/классификатор по каталогу приёмов (страх, ложная дихотомия,
  цифра-без-источника, апелляция к авторитету и т.д.) с указанием span'а в тексте.

**Структура затрат (Cost Structure):**
- API Fable 5 + Haiku (× запросов, с учётом кэша) — заполнить из реальных цен
- Хостинг (Railway/Hetzner) — у тебя уже посчитано в трекере расходов
- KazLLM — self-hosted, только вычисления

**Устойчивость (соцпроект):**
- Измеряемый эффект: % сообщений, где пользователь изменил решение делиться; кол-во проверок.
- Ответ на «монетизацию при CC-BY-NC»: соцпроект → гранты (Medianet/Soros), B2G-пилот с
  акиматами по медиаграмотности, white-label для школьных медиа. Коммерческую версию —
  на модели без NC-лицензии (это roadmap-слайд).
